ONLINE EXAM — BULK QUESTION UPLOAD FORMAT
==========================================

Paste this into the "Add questions" box on /online-exams (after opening the
exam), one question per line, pipe-separated (|), in this exact order:

CLASS|SUBJECT|CHAPTER|QUESTION_TEXT|OPTION_A|OPTION_B|OPTION_C|OPTION_D|CORRECT_ANSWER|DIFFICULTY|MARKS

Rules:
  - CLASS must exactly match the exam's own class (shown at the top of the
    question-upload box) on every line, or the whole paste is rejected.
  - CORRECT_ANSWER is one letter: A, B, C or D.
  - DIFFICULTY is EASY, MEDIUM or HARD.
  - MARKS is a whole number, 1 or more.
  - The whole paste is all-or-nothing: if any line is malformed, nothing is
    saved and you get a line-by-line list of what's wrong.

Four sample exams (4 questions each) have already been created and
published on the live system — one per class currently in the Students
table — so the feature can be seen working end to end right now:

  /online-exams?examId=3   Sample Test - 11th Science PCB
  /online-exams?examId=4   Sample Test - 11th Science PCM
  /online-exams?examId=5   Sample Test - 11th NEET ANKUR
  /online-exams?examId=6   Sample Test - 12th Science PCB
