📊 Overview

The Jocata API Suite provides compliance screening capabilities, including name screening, transaction screening, and health checks. All APIs support encrypted requests/responses using IndusInd SDK encryption.

APIs Available

🔍 Name Screening

Screen individual/entity names against sanction and watchlists

Endpoint: /apiscreening/v1

💰 Transaction Screening

Screen transaction parties (sender/receiver) against compliance lists

Endpoint: /transactionscreening/v1

🏥 Health Check

Verify API gateway connectivity and encryption capability

Endpoint: /health

Key Features

  • End-to-End Encryption: All requests/responses encrypted using IndusInd SDK
  • Multiple Identifiers: Support for PAN, Aadhar, Passport, GST, CIN, DIN, and more
  • Rich Address Data: Location-based screening with city, state, country, pincode
  • Real-time Results: Immediate match/no-match responses
  • Transaction Context: Support for transaction-specific screening with account details
  • Local Reverse Option: Demo/testing mode for reverse flow without network
⚠️ Important: The test page (jocataApiTest.jsp) is for testing only. Remove or restrict before production deployment.

⚙️ Setup & Configuration

Prerequisites

  • JocataClient library in classpath
  • IndusInd API client SDK (crypto library)
  • api-client.properties configuration file
  • Valid Jocata API credentials (API key, API secret)
  • Network access to Jocata API gateway

Configuration File: api-client.properties

📝 api-client.properties (Location: Constants.configFilePath) # Jocata API Configuration jocata.api.url=https://api.jocata.com # API Gateway URL jocata.api.key=YOUR_API_KEY # API Key from Jocata jocata.api.secret=YOUR_API_SECRET # API Secret for encryption jocata.encryption.algorithm=AES256 # Encryption algorithm jocata.encryption.keysize=256 # Key size in bits # Proxy settings (if applicable) jocata.proxy.enabled=false jocata.proxy.host= jocata.proxy.port= jocata.proxy.username= jocata.proxy.password= # Timeout settings jocata.timeout.connect=10000 # 10 seconds jocata.timeout.read=30000 # 30 seconds

JocataClientHolder - Singleton Pattern

☕ Java Implementation package com.api.exh.integration.jocata; import com.fable.apiclient.jocata.JocataClient; import com.api.exh.component.util.Constants; public class JocataClientHolder { private static JocataClient instance; private static final Object lock = new Object(); public static JocataClient get() throws Exception { if (instance == null) { synchronized (lock) { if (instance == null) { // Load from api-client.properties instance = new JocataClient(Constants.configFilePath); } } } return instance; } public static void reset() { synchronized (lock) { instance = null; } } }

🔍 Name Screening API

POST

Purpose

Screen individuals and entities against global sanctions, watchlists, and compliance lists based on name and identifiers.

Endpoint

/apiscreening/v1

Request Structure

Request JSON Structure { "rampRequest": { "listMatchingPayload": { "requestListVO": { "businessUnit": "RAMP", "subBusinessUnit": "API", "requestType": "API", "requestUuId": "IBL-TEST-0001", "requestVOList": [ { "name": "ERIKA CSANYI", "entityName": "", "dob": "010169", "nationality": "HUNGARIAN", "placeOfBirth": "BUDAPEST", "country": "INDIA", "state": "MAHARASHTRA", "city": "MUMBAI", "pincode": "400001", "address": "123 Business Park", "concatAddress": "123 Business Park, MUMBAI, MAHARASHTRA, INDIA", "pan": "AABCD1234A", "passport": "P123456789", "aadhar": "123456789012", "customerId": "CUST-MATCH-01", "phone": "+91-9876543210", "email": "test@example.com" } ] } } } }

Request Parameters

Field Type Required Description
name String ✓ Full name of individual to screen. Format: DDMMMYYYY for DOB
entityName String Entity name (for corporate/org screening)
dob String Date of birth. Format: DDMMMYYYY (e.g., 010169 for Jan 1, 1969)
nationality String Nationality/country of origin
country String Current country of residence
state String State/province
city String City
pincode String Postal code
address String Full address
concatAddress String Concatenated address (street, city, state, country)
pan String Indian PAN (Permanent Account Number)
aadhar String Indian Aadhar number
passport String Passport number
customerId String Your internal customer/party ID

Response Structure

Response JSON { "rampResponse": { "statusCode": "000", "statusMessage": "Success", "listMatchingResponse": { "responseListVO": [ { "requestId": "IBL-TEST-0001", "responseId": "RESP-2024-001", "matchFlag": "Y", "matchCount": 1, "matches": [ { "matchedName": "ERIKA CSANYI", "matchType": "Name Match", "matchProbability": "98", "listCode": "OFAC", "listName": "US Treasury OFAC", "caseId": "25072103", "remarks": "True Match - Sanction list" } ] } ] } } }

Response Fields

Field Description
statusCode 000 = Success, others indicate error. Check statusMessage
statusMessage Human-readable status message
matchFlag Y = Match found, N = No match
matchCount Number of matches found
matches[] Array of matching records
matchType Type of match: Name, DOB, Address, ID, etc.
matchProbability Match confidence score (0-100%)
listCode Compliance list code (OFAC, EU, UN, RBI, etc.)

Code Example

public class NameScreeningService { public ScreeningResult screenName(String name, String dob, String nationality, String country) throws Exception { JocataClient jc = JocataClientHolder.get(); // Build request payload Map<String, Object> partyVO = new LinkedHashMap<>(); partyVO.put("name", name); partyVO.put("dob", dob); // Format: DDMMMYYYY partyVO.put("nationality", nationality); partyVO.put("country", country); partyVO.put("customerId", UUID.randomUUID().toString()); Map<String, Object> requestListVO = new LinkedHashMap<>(); requestListVO.put("businessUnit", "RAMP"); requestListVO.put("subBusinessUnit", "API"); requestListVO.put("requestType", "API"); requestListVO.put("requestUuId", "IBL-" + System.currentTimeMillis()); requestListVO.put("requestVOList", Collections.singletonList(partyVO)); Map<String, Object> payload = new LinkedHashMap<>(); payload.put("rampRequest", Collections.singletonMap( "listMatchingPayload", Collections.singletonMap("requestListVO", requestListVO) )); // Send encrypted request (encryption handled internally) String jsonRequest = Json.write(payload); String jsonResponse = jc.invoke("/apiscreening/v1", jsonRequest); // Parse response Map<String, Object> responseMap = Json.parseObject(jsonResponse); Map<String, Object> rampResponse = (Map) responseMap.get("rampResponse"); RampResponse result = Beans.fromMap(rampResponse, RampResponse.class); // Create result object ScreeningResult screeningResult = new ScreeningResult(); screeningResult.setStatusCode(result.statusCode); screeningResult.setStatusMessage(result.statusMessage); screeningResult.setMatch(result.isMatch()); screeningResult.setMatchCount(result.getMatchCount()); return screeningResult; } }

💰 Transaction Screening API

POST

Purpose

Screen transaction parties (sender and receiver) in the context of a specific transaction to detect potential compliance risks.

Endpoint

/transactionscreening/v1

Request Structure

Request JSON Structure { "rampRequest": { "listMatchingPayload": { "requestListVO": { "businessUnit": "RAMP", "subBusinessUnit": "API", "requestType": "TSG", "tranId": "TXN-90001", "accountNumber": "ACC-12345", "remarks": "outward remittance", "requestVOList": [ { "type": "sender", "customerType": "I", "name": "JOHN DOE", "entityName": "", "dob": "010175", "nationality": "USA", "country": "USA", "state": "NEW YORK", "city": "NEW YORK", "pincode": "10001", "address": "456 Business Ave", "contactAddress": "456 Business Ave, NEW YORK, NY, USA", "pan": "AABCD1234B", "passport": "P987654321", "customerId": "CUST-SENDER-01", "phone": "+1-2125551234", "email": "sender@example.com" }, { "type": "receiver", "customerType": "I", "name": "RAJESH KUMAR", "dob": "010180", "nationality": "INDIAN", "country": "INDIA", "state": "MAHARASHTRA", "city": "MUMBAI", "pincode": "400001", "aadhar": "987654321012", "customerId": "CUST-RECEIVER-01" } ] } } } }

Key Differences from Name Screening

Name Screening

  • requestType: "API"
  • Single party screening
  • concatAddress field
  • No transaction context

Transaction Screening

  • requestType: "TSG"
  • Multiple parties (sender/receiver)
  • contactAddress field
  • Transaction ID, account number

Request Parameters

Field Type Required Description
type String ✓ Party type: sender, receiver, port, vessel
customerType String ✓ I = Individual, E = Entity/Organization
tranId String ✓ Unique transaction ID (e.g., TXN-90001)
accountNumber String Account number for the transaction
remarks String Transaction purpose/remarks
contactAddress String Contact address of party (different from concatAddress)
name String ✓ Party name. Format: DD/MM/YYYY for DOB in txn

Code Example

public class TransactionScreeningService { public ScreeningResult screenTransaction(String tranId, String senderName, String receiverName, String accountNumber, String remarks) throws Exception { JocataClient jc = JocataClientHolder.get(); // Build sender party Map<String, Object> senderVO = new LinkedHashMap<>(); senderVO.put("type", "sender"); senderVO.put("customerType", "I"); senderVO.put("name", senderName); senderVO.put("dob", "01/01/1975"); senderVO.put("nationality", "USA"); senderVO.put("customerId", UUID.randomUUID().toString()); // Build receiver party Map<String, Object> receiverVO = new LinkedHashMap<>(); receiverVO.put("type", "receiver"); receiverVO.put("customerType", "I"); receiverVO.put("name", receiverName); receiverVO.put("dob", "01/01/1980"); receiverVO.put("nationality", "INDIAN"); receiverVO.put("country", "INDIA"); receiverVO.put("customerId", UUID.randomUUID().toString()); // Build request Map<String, Object> requestListVO = new LinkedHashMap<>(); requestListVO.put("businessUnit", "RAMP"); requestListVO.put("subBusinessUnit", "API"); requestListVO.put("requestType", "TSG"); requestListVO.put("tranId", tranId); requestListVO.put("accountNumber", accountNumber); requestListVO.put("remarks", remarks); requestListVO.put("requestVOList", Arrays.asList(senderVO, receiverVO)); Map<String, Object> payload = new LinkedHashMap<>(); payload.put("rampRequest", Collections.singletonMap( "listMatchingPayload", Collections.singletonMap("requestListVO", requestListVO) )); // Send request String jsonRequest = Json.write(payload); String jsonResponse = jc.invoke("/transactionscreening/v1", jsonRequest); // Parse and return result return parseResponse(jsonResponse); } }

🔄 Reverse API (Local Demo)

LOCAL

Purpose

This is a local demonstration of the reverse flow. It shows how to decrypt a reverse notification callback from Jocata without making a network request. Used for testing and development.

Use Case: Incoming Callback

When Jocata needs to update you on a case (e.g., case closed, new matches), it sends an encrypted reverse notification. You decrypt it locally to extract the case data.

Request Structure

Reverse Request JSON (Before Encryption) { "requestUuId": "IBL-TEST-0001", "buCode": "RAMP", "subBuCode": "API", "uniqueRequestId": "SSG115351250721115220196", "screeningStatus": "Closed-True Match", "caseId": "25072103", "customerId": "JCT-12345", "remarks": "Case review completed", "Comments": "Match confirmed by compliance officer" }

Response Structure (After Local Decode)

Parsed Result { "caseId": "25072103", "status": "Closed-True Match", "uniqueRequestId": "SSG115351250721115220196", "customerId": "JCT-12345", "remarks": "Case review completed", "comments": "Match confirmed by compliance officer" }

Code Example

public class ReverseCallbackHandler { public void handleJocataCallback(String encryptedEnvelope) throws Exception { JocataClient jc = JocataClientHolder.get(); // Decrypt the envelope locally (no network call) ReverseRequest reverseData = jc.parseReverse(encryptedEnvelope); // Now you have the decrypted data String caseId = reverseData.caseId; String status = reverseData.screeningStatus; String requestId = reverseData.uniqueRequestId; // Update your database with case status updateCaseStatus(caseId, status); // Log the update Logger.info("Case " + caseId + " updated: " + status); // Notify compliance team if match found if ("Closed-True Match".equals(status)) { notifyComplianceTeam(caseId, requestId); } } private void updateCaseStatus(String caseId, String status) { // Database update logic // UPDATE jocata_cases SET status = ? WHERE case_id = ? } private void notifyComplianceTeam(String caseId, String requestId) { // Send email or create alert // Email: Case {caseId} requires compliance review } }

Webhook Integration (Servlet)

@WebServlet("/jocata/reverse-callback") public class JocataReverseServlet extends HttpServlet { protected void doPost(HttpServletRequest request, HttpServletResponse response) throws ServletException, IOException { try { // Read encrypted envelope from request body BufferedReader reader = request.getReader(); StringBuilder sb = new StringBuilder(); String line; while ((line = reader.readLine()) != null) { sb.append(line); } String encryptedEnvelope = sb.toString(); // Decrypt and process JocataClient jc = JocataClientHolder.get(); ReverseRequest reverseData = jc.parseReverse(encryptedEnvelope); // Process the callback new ReverseCallbackHandler().handleJocataCallback(reverseData); // Send success response response.setStatus(HttpServletResponse.SC_OK); response.setContentType("application/json"); response.getWriter().write("{\"status\": \"success\"}"); } catch (Exception e) { Logger.error("Error processing reverse callback", e); response.setStatus(HttpServletResponse.SC_INTERNAL_SERVER_ERROR); response.getWriter().write("{\"status\": \"error\", \"message\": \"" + e.getMessage() + "\"}"); } } }

🏥 Health Check API

GET

Purpose

Verify that Jocata API gateway is reachable, encryption is working, and your configuration is correct.

Endpoint

GET /health

Response Structure

Health Check Response { "status": "UP", "gatewayReachable": true, "encryptOk": true, "configValid": true, "httpStatus": 200, "apiVersion": "1.0.2", "timestamp": "2024-01-15T10:30:45Z", "responseTime": "245ms" }

Response Fields

Field Description
status UP = All healthy, DOWN = Issues found
gatewayReachable true = Can connect to API gateway
encryptOk true = Encryption/decryption working
configValid true = Configuration is valid
httpStatus HTTP response code (200 = OK)
responseTime Time taken for health check

Code Example

public class HealthCheckService { public HealthStatus checkJocataHealth() throws Exception { long startTime = System.currentTimeMillis(); try { JocataClient jc = JocataClientHolder.get(); Map<String, Object> health = jc.healthCheck(); long duration = System.currentTimeMillis() - startTime; HealthStatus status = new HealthStatus(); status.setStatus((String) health.get("status")); status.setGatewayReachable((Boolean) health.get("gatewayReachable")); status.setEncryptOk((Boolean) health.get("encryptOk")); status.setHttpStatus((Integer) health.get("httpStatus")); status.setResponseTime(duration + "ms"); status.setTimestamp(new Date()); return status; } catch (Exception e) { HealthStatus status = new HealthStatus(); status.setStatus("DOWN"); status.setError(e.getMessage()); return status; } } // Can be called periodically to monitor API health public void monitorHealth() { ScheduledExecutorService executor = Executors.newScheduledThreadPool(1); executor.scheduleAtFixedRate(() -> { try { HealthStatus status = checkJocataHealth(); if (!"UP".equals(status.getStatus())) { alertOps("Jocata API Health: " + status.getStatus()); } } catch (Exception e) { logger.error("Health check failed", e); } }, 0, 5, TimeUnit.MINUTES); } }

🔧 Integration Patterns

Pattern 1: Synchronous Screening (Real-time)

Use Case: During customer onboarding, immediately screen the customer
  1. User submits customer details in form
  2. Application sends Name Screening request to Jocata
  3. Jocata returns match result immediately
  4. Application displays result and either approves or blocks onboarding
  5. No database update needed from your side (unless archiving)
Synchronous Pattern Implementation public class OnboardingService { public OnboardingResult onboardCustomer(Customer customer) throws Exception { // Screen customer immediately ScreeningResult result = screeningService.screenName( customer.getName(), customer.getDob(), customer.getNationality(), customer.getCountry() ); if (result.isMatch()) { // Match found - block onboarding return OnboardingResult.BLOCKED("Screening match found"); } else { // No match - proceed with onboarding customerRepository.save(customer); return OnboardingResult.APPROVED(); } } }

Pattern 2: Asynchronous Screening (Batch)

Use Case: Screen multiple customers/transactions in batch during off-peak hours
  1. Collect customer records throughout the day
  2. At night, process batch screening request
  3. Jocata returns results for all records
  4. Update database with screening status
  5. Alert compliance team about any matches
Batch Screening Pattern @Scheduled(cron = "0 0 2 * * *") // Run at 2 AM daily public void batchScreening() throws Exception { List<Customer> unscreenedCustomers = customerRepository.findByScreeningStatus("PENDING"); for (Customer customer : unscreenedCustomers) { try { ScreeningResult result = screeningService.screenName( customer.getName(), customer.getDob(), customer.getNationality(), customer.getCountry() ); // Update database customer.setScreeningStatus(result.isMatch() ? "MATCHED" : "CLEAR"); customer.setScreeningResult(Json.write(result)); customerRepository.save(customer); // Alert if match if (result.isMatch()) { complianceAlert.send("Match: " + customer.getName()); } } catch (Exception e) { logger.error("Screening failed for customer: " + customer.getId(), e); customer.setScreeningStatus("ERROR"); customerRepository.save(customer); } } }

Pattern 3: Transaction Screening (High Volume)

Use Case: Screen every transaction (sender/receiver) for compliance
  1. Transaction initiated by user
  2. System extracts sender and receiver details
  3. Sends transaction screening request to Jocata
  4. If matches found, transaction blocked and escalated
  5. If clear, transaction proceeds normally

Pattern 4: Case Management (Reverse Flow)

Use Case: Handle Jocata case updates and manual review closure
  1. Case created when match found in screening
  2. Compliance team reviews case in Jocata UI
  3. Jocata sends reverse callback when case resolved
  4. Your system receives and decrypts callback
  5. Update case status in your database
  6. Unblock transaction if case cleared

package com.api.exh.integration.jocata; import com.fable.apiclient.Json; import com.fable.apiclient.ApiException; import com.fable.apiclient.jocata.JocataClient; import java.util.*; @Service public class ComplianceScreeningService { private static final Logger logger = LoggerFactory.getLogger(ComplianceScreeningService.class); // ===== NAME SCREENING ===== public ScreeningResult screenName(String name, String dob, String nationality) throws Exception { try { JocataClient jc = JocataClientHolder.get(); Map<String, Object> partyVO = buildPartyVO(name, dob, nationality); Map<String, Object> requestListVO = buildNameScreeningRequest(partyVO); Map<String, Object> payload = buildPayload("API", "/apiscreening/v1", requestListVO); String response = jc.invoke("/apiscreening/v1", Json.write(payload)); return parseScreeningResponse(response); } catch (ApiException e) { logger.error("Screening API error: " + e.kind(), e); throw new ScreeningException("API error: " + e.getMessage(), e); } } // ===== TRANSACTION SCREENING ===== public ScreeningResult screenTransaction(String tranId, String senderName, String receiverName) throws Exception { try { JocataClient jc = JocataClientHolder.get(); Map<String, Object> senderVO = buildPartyVO(senderName, null, null); senderVO.put("type", "sender"); senderVO.put("customerType", "I"); Map<String, Object> receiverVO = buildPartyVO(receiverName, null, null); receiverVO.put("type", "receiver"); receiverVO.put("customerType", "I"); Map<String, Object> requestListVO = buildTransactionScreeningRequest( tranId, Arrays.asList(senderVO, receiverVO) ); Map<String, Object> payload = buildPayload("TSG", "/transactionscreening/v1", requestListVO); String response = jc.invoke("/transactionscreening/v1", Json.write(payload)); return parseScreeningResponse(response); } catch (ApiException e) { logger.error("Transaction screening API error: " + e.kind(), e); throw new ScreeningException("API error: " + e.getMessage(), e); } } // ===== HEALTH CHECK ===== public HealthStatus checkHealth() throws Exception { try { JocataClient jc = JocataClientHolder.get(); Map<String, Object> health = jc.healthCheck(); HealthStatus status = new HealthStatus(); status.setStatus((String) health.get("status")); status.setGatewayReachable((Boolean) health.getOrDefault("gatewayReachable", false)); status.setEncryptOk((Boolean) health.getOrDefault("encryptOk", false)); return status; } catch (Exception e) { logger.error("Health check failed", e); HealthStatus status = new HealthStatus(); status.setStatus("DOWN"); status.setError(e.getMessage()); return status; } } // ===== HELPER METHODS ===== private Map<String, Object> buildPartyVO(String name, String dob, String nationality) { Map<String, Object> vo = new LinkedHashMap<>(); vo.put("name", name); if (dob != null) vo.put("dob", dob); if (nationality != null) vo.put("nationality", nationality); vo.put("customerId", UUID.randomUUID().toString()); return vo; } private Map<String, Object> buildNameScreeningRequest(Map<String, Object> partyVO) { Map<String, Object> rlvo = new LinkedHashMap<>(); rlvo.put("businessUnit", "RAMP"); rlvo.put("subBusinessUnit", "API"); rlvo.put("requestType", "API"); rlvo.put("requestUuId", UUID.randomUUID().toString()); rlvo.put("requestVOList", Collections.singletonList(partyVO)); return rlvo; } private Map<String, Object> buildTransactionScreeningRequest(String tranId, List<Map<String, Object>> parties) { Map<String, Object> rlvo = new LinkedHashMap<>(); rlvo.put("businessUnit", "RAMP"); rlvo.put("subBusinessUnit", "API"); rlvo.put("requestType", "TSG"); rlvo.put("tranId", tranId); rlvo.put("requestVOList", parties); return rlvo; } private Map<String, Object> buildPayload(String requestType, String path, Map<String, Object> requestListVO) { Map<String, Object> payload = new LinkedHashMap<>(); Map<String, Object> innerMap = Collections.singletonMap("requestListVO", requestListVO); Map<String, Object> payloadMap = Collections.singletonMap("listMatchingPayload", innerMap); payload.put("rampRequest", payloadMap); return payload; } private ScreeningResult parseScreeningResponse(String jsonResponse) throws Exception { Map<String, Object> responseMap = Json.parseObject(jsonResponse); Map<String, Object> rampResponse = (Map) responseMap.get("rampResponse"); ScreeningResult result = new ScreeningResult(); result.setStatusCode((String) rampResponse.get("statusCode")); result.setStatusMessage((String) rampResponse.get("statusMessage")); List<Map<String, Object>> responseList = (List) ((Map) rampResponse.get("listMatchingResponse")).get("responseListVO"); if (responseList != null && !responseList.isEmpty()) { Map<String, Object> first = responseList.get(0); result.setMatch("Y".equals(first.get("matchFlag"))); result.setMatchCount((Integer) first.getOrDefault("matchCount", 0)); result.setMatches((List) first.get("matches")); } return result; } }
